
## Step to Create AWS Knowlege Base on BedRock console
1. __KB name__  
Enter name for the Knowlege Base
2. __Data source name__  
Select Data Store (use S3 for Data Store)
You should already have the book.txt uploaded to the S3 bucket
3. __S3 URI__  
Select the book.txt from the S3 buckett
4. __Access control list__  
Disabled 
5. __Content parsing and chunking__  
Use the default parsing and chunking strategy  
6. __Sync schedule__. 
On Demand
